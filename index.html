            Backup e configurações

            Seus dados ficam salvos apenas neste celular. Faça backup regularmente para não perder tudo caso troque ou perca o aparelho.

            Importe o extrato baixado do internet banking (.ofx/.qfx) ou uma planilha (.csv) com colunas de data, valor e descrição. As transações entram com a categoria "A categorizar" — edite depois para organizar nos orçamentos.

            Método Kakeibo: agrupe suas categorias em Sobrevivência, Lazer, Cultura ou Extra para ver o resumo por grupo no Relatório.

            Consultor com IA: informe sua própria chave da API da Anthropic (gerada em console.anthropic.com) para usar o botão "Analisar com IA" no Relatório. A chave fica salva só neste celular, nunca entra no backup, e cada análise é enviada direto para a Anthropic quando você pede — não é automático.
