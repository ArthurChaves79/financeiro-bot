SIG View

    Configurações

    Aponte o programa para os recursos da rede local. Salvar recarrega a página.

    Coloque um ou mais arquivos .mbtiles na pasta data\maps (do lado do programa) pra eles aparecerem aqui pra escolher — sem precisar digitar caminho.

    Deixe /tiles/style.json para usar o mapa embutido (arquivo acima) — só troque se for usar um servidor de tiles externo (ex: TileServer GL).

    Só vale pro mapa embutido (vetorial) — usa o mesmo arquivo de mapa, só muda as cores.

    Arquivo numa pasta de rede com o número da versão mais nova disponível (peça pro TI deixar isso pronto). Deixe em branco pra não checar nada.

    🔧 Manutenção

    Rode aqui os scripts de manutenção do índice de busca e das camadas, sem precisar abrir um terminal. Os caminhos são os mesmos que você digitaria na linha de comando.
